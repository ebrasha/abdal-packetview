## 🚀 معرفی پروژه

**Abdal PacketView** یک ابزار اندرویدی برای ضبط پکت (Packet Capture) و تحلیل ترافیک شبکه است که کمک می کند کاربر بفهمد دستگاه اندرویدی او چه داده هایی را روی شبکه ارسال و دریافت می کند.

این نرم افزار با استفاده از `VpnService` اندروید یک اینترفیس محلی **TUN** می سازد، پکت های خام IP را ضبط می کند، اطلاعات شبکه را رمزگشایی می کند و خروجی را در قالب مدرن **PCAPNG** ذخیره می کند تا در ابزارهایی مثل **Wireshark** و **tshark** قابل بررسی باشد.

این پروژه برای پژوهشگران امنیت، توسعه دهندگان اندروید، مهندسان تست، تحلیلگران شبکه و کاربران حرفه ای ساخته شده است که می خواهند بدون روت کردن گوشی، دید عملی و قابل خروجی گرفتن نسبت به ترافیک دستگاه خود داشته باشند.

## ❓ چرا این پروژه ساخته شده است؟

تحلیل ترافیک شبکه در اندروید معمولا به گوشی روت شده، کامپیوتر، Wireshark، پراکسی، اتصال USB یا تنظیمات پیچیده شبکه نیاز دارد. این روش برای بسیاری از کاربران کند، شکننده و سخت است.

**Abdal PacketView** برای ساده کردن همین فرایند ساخته شده است. این برنامه امکان ضبط محلی، کنترل شده و روی دستگاه را فراهم می کند تا کاربر بتواند ترافیک اپلیکیشن ها را بررسی کند، پکت ها را به اپلیکیشن صاحب آن نسبت دهد و خروجی استاندارد برای تحلیل های عمیق تر بسازد.

## ✨ قابلیت های کلیدی

- 🛰️ **ضبط پکت روی خود دستگاه** با استفاده از `VpnService` اندروید و اینترفیس محلی TUN
- 🔐 **بدون نیاز به روت** و بدون نیاز به سرور بیرونی برای ضبط ترافیک
- 🔌 **حفظ اتصال اینترنت** در زمان فعال بودن ضبط
- 🧬 **رمزگشایی پکت ها** برای ترافیک IPv4، IPv6، TCP، UDP و ICMP
- 🏷️ **نسبت دادن پکت به اپلیکیشن** بر اساس UID، همراه با نام اپ و نام پکیج
- 🧭 **تونل تفکیکی اپلیکیشن ها (App Split Tunnel)** با حالت های Route via Tunnel و Bypass Tunnel
- 🔎 **فیلترهای نمایشی شبیه Wireshark** برای پروتکل ها، فیلدها، پورت ها، طول پکت و منطق Boolean
- 💾 **خروجی PCAPNG** داخل بسته ZIP همراه با فایل `statistics.json`
- 📊 **آمار نشست ضبط** شامل تعداد پکت ها، حجم داده، مدت زمان و وضعیت App Split
- ⚡ **گزینه های بهینه سازی کارکرد** مثل جداسازی تحلیل از فوروارد، کش LRU برای نسبت دهی و کاهش مصرف حافظه
- 📚 **مرکز راهنمای داخلی** برای کمک به نوشتن فیلترهای نمایشی
- 🧠 **Proto Tuts+** برای یادگیری مفاهیم پروتکل ها و امنیت سایبری
- 🌙 **رابط کاربری تیره و مدرن** ساخته شده با Jetpack Compose و پشتیبانی از RTL

## 🧩 کاربردها

- 🔍 بررسی رفتار شبکه ای اپلیکیشن های اندروید در زمان توسعه یا تست
- 🛡️ تحلیل ترافیک مشکوک یا غیرمنتظره روی دستگاه شخصی
- 🧪 دیباگ کردن API، DNS، QUIC، HTTPS و جریان های UDP
- 📦 خروجی گرفتن از ضبط ها برای Wireshark، tshark یا گزارش فنی
- 🧭 مقایسه ترافیک اپلیکیشن های انتخاب شده با App Split
- 📚 یادگیری عملی پروتکل های شبکه با ضبط واقعی روی دستگاه

## 📦 قالب خروجی

زمانی که ضبط ذخیره می شود، **Abdal PacketView** یک بسته ZIP می سازد که شامل این فایل ها است:

```text
Abdal_PacketView_<timestamp>.pcapng
statistics.json
```

فایل `.pcapng` با Wireshark و tshark سازگار است. هر پکت می تواند شامل متادیتای نسبت دهی به اپلیکیشن، مثل نام اپ و نام پکیج باشد. فایل `statistics.json` هم خلاصه ای خوانا از نشست ضبط را نگه می دارد؛ از جمله تعداد پکت ها، حجم داده، مدت زمان، زمان تولید و وضعیت فعال App Split.

این پروژه همچنین از گزینه های سفارشی PCAPNG استفاده می کند که زیر شماره سازمانی اختصاصی IANA یعنی **66033** ثبت شده برای **Abdal Security Group** شناسایی می شوند.



## ▶️ نحوه استفاده

1. برنامه را باز کنید و وارد تب **Capture** شوید.
2. روی **Start** بزنید و پنجره رضایت VPN اندروید را تایید کنید.
3. هنگام استفاده عادی از دستگاه، پکت ها در جدول زنده نمایش داده می شوند.
4. روی هر ردیف پکت بزنید تا جزئیات رمزگشایی شده آن را ببینید.
5. از **App Split** برای ضبط فقط اپلیکیشن های انتخابی یا مستثنا کردن اپلیکیشن های مشخص استفاده کنید.
6. فیلترهای نمایشی را وارد کنید، مثل:

```text
https
udp && port == 53
ip.addr == 8.8.8.8
```

7. با **Save Capture** یک بسته ZIP شامل فایل `.pcapng` و `statistics.json` بسازید.
8. فایل خروجی را با Wireshark، tshark یا هر فرایند تحلیلی دیگر به اشتراک بگذارید.
